# Automation - Platform API

This repository contains a proof of concept for testing and automation. It's a [Maven](https://maven.apache.org/) project using [WebTau](https://testingisdocumenting.org/webtau/getting-started/what-is-this) for **Web T**est **au**tomation. Essentially, it can be other test framework like JUnit or cucumber testing.
